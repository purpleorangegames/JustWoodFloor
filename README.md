# JustWoodFloor

A retexture of the current wood floor, it will override it as the default wood floor.

Added a light variation, they are both accessible at the same place, it will bring a list when you click on wood floor.

Inspired by GloomyFurniture wood floor.
https://steamcommunity.com/sharedfiles/filedetails/?id=1558635181

Steam version: https://steamcommunity.com/sharedfiles/filedetails/?id=3189695842

If you want to change your stone tiles texture as well, you can check this other mod:
https://steamcommunity.com/sharedfiles/filedetails/?id=3189952629

You can check out more floors, including this one, in this pack here
https://steamcommunity.com/sharedfiles/filedetails/?id=3193619828

## Versions

1.7 uses the 1.7 folder, 1.4 to 1.6 use the old files in the Legacy folder.

The light floor is only added when JustFloorTiles isn't active, since that mod already has it (NotFound folder).
